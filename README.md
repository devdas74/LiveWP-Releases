# LiveStagix

An Android live wallpaper app for photos and videos.

## Features

- Photo and video live wallpapers with **Live Stage** preview.
- Device-aware media preparation for wallpaper cropping and compatible output.
- Gyroscope-based motion effects for photos.
- Video enhancements: **Frame Interpolation** and **Smart Upscale** on supported devices.
- Native Floating Island-style runtime status.
- Prepared media can be reused without repeating preparation.

## Manual

1. [Download the latest APK](https://github.com/devdas74/LiveWP-Releases/releases/latest).
2. Install and open LiveStagix.
3. Select a photo or video, or find a photo using wallpaper search.
4. Open **Live Stage** and tap **Prepare**.
5. When preparation finishes, tap **Set as Wallpaper**.
6. Complete Android's wallpaper preview and confirmation steps.

Compatibility and available features can vary by device and Android version.
